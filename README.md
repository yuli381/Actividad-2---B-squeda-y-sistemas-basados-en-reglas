# 🚌 Sistema Inteligente Basado en Conocimiento para TransMilenio

Este proyecto consiste en un **Sistema Basado en Conocimiento (SBC)** desarrollado en Python que aplica lógica de representación del conocimiento y reglas de inferencia para determinar la mejor ruta de viaje entre dos estaciones en el sistema de transporte masivo **TransMilenio**.

Proyecto desarrollado para la Actividad 3 del curso de **Sistemas Inteligentes / Inteligencia Artificial Avanzada**.

---

## 📋 Requisitos Previos

Para ejecutar este proyecto solo necesitas tener instalado **Python 3.8 o superior** en tu sistema operativo. No se requieren librerías de terceros (se utiliza la librería estándar de Python).

Verifica tu versión de Python ejecutando en la terminal:

```bash
python --version
# o en sistemas Linux/Mac:
python3 --version
🚀 Instrucciones de Instalación y Ejecución
Sigue estos pasos para clonar y ejecutar la aplicación en tu máquina local:

1. Clonar el repositorio
git clone <URL_DE_TU_REPOSITORIO_GIT>
cd <NOMBRE_DE_LA_CARPETA_DEL_PROYECTO>
2. Ejecutar el script principal
Ejecuta el archivo Python desde la terminal o consola de comandos:

En Windows:
python transmilenio_sbc.py
En macOS / Linux:
python3 transmilenio_sbc.py
